# CityNest presentation image sources

The presentation seed uses real photographs for visual realism. These are presentation assets, not claims that the photographed objects belong to the listed sellers. Replace them with seller-uploaded photographs for a public marketplace.

## Public-launch rule

Do not use presentation photographs as proof that an item is actually owned by a CityNest seller. Public listings should use photographs uploaded by the actual seller/owner or appropriately licensed assets.
